# Сборка отчётов по аудиту

## Что делает

Находки от агента — это цитата, нарушение и `block_id`. Отчёт делает из них
рабочий документ:

1. **Приклеивает локацию.** По `block_id` находится блок, по нему — страница из
   карты страниц и координаты в таблице. Получается «Страница 23, Таблица 22,
   строка 31, ячейка 3».
2. **Отсеивает мусор.** Находки с несуществующим `block_id` выбрасываются —
   выдуманное место в отчёт не попадёт. Убираются дубликаты, возникшие на
   перекрытии чанков.
3. **Нумерует** сквозным `E001…` в порядке документа, а не в порядке появления.
4. **Собирает три файла.**

## Запуск

```bash
"<skill>/scripts/run.cmd" build_report.py --work "<work_dir>"
```

Если часть чанков не проверена, скрипт откажется работать — это защита от отчёта
по половине документа. Осознанно собрать частичный отчёт можно флагом
`--allow-incomplete`, в нём будет отметка `partial` и предупреждение.

Параметры:

- `--out` — куда положить результат, по умолчанию `<work_dir>/output`.
- `--report-lang` — `ru` (по умолчанию) или `en`.
- `--allow-incomplete` — собрать отчёт по тому, что есть.

## Что получается

- `*__audit_table.xlsx` — карта ошибок: ID, человеческая локация, страница, тип
  объекта, таблица/строка/ячейка/абзац, цитата, проблема, рекомендация, режим
  правки, уверенность, старый и новый текст, block_id, технический адрес.
- `*__audit_report.docx` — краткий отчёт для чтения и пересылки.
- `*__annotated.docx` — копия документа с якорями `⟦E001⟧` у каждой ошибки:
  открываешь и идёшь по местам.
- `*__audit.json` — те же данные машинно, для повторной сборки.

## Снять якоря

```bash
"<skill>/scripts/run.cmd" build_report.py --strip-anchors "<...>__annotated.docx"
```

Рядом появится копия без якорей. Исходный размеченный файл не трогается.

## Если страниц нет

При подготовке с `--no-pages` (или когда Word недоступен) колонка страниц будет
пустой — остальная локация, включая таблицу, строку и ячейку, работает как
обычно.
